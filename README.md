NuMa: Your Numeracy Mate

Teaching numeracy step-by-step. The NuMa system uses a map of mathematical epistemology to track the learner's progress, presenting increasingly complex concepts whilst making sure that each step is stable before moving on. 

Rather than a ladder with a linear series of steps, think of a web of interconnected nodes (a DAG).

Each node represents a concept, skill, or strategy, connected by prerequisite edges to the other nodes it builds on. Mastery isn't assumed or self-reported — it's worked out from how the learner performs on concrete exercises that test each skill, and (more uncertainly) which strategy the exercise suggests they used. That map of nodes and edges — plus the exercises that assess them — always tells the app what a learner is ready for next: the frontier of what's within reach but not yet mastered.
